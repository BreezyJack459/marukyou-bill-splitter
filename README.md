# 丸京 · 食飯分帳

按餐點原價比例分攤實付金額嘅廣東話計算器。純 HTML、CSS 同 JavaScript，毋須安裝套件。

## 功能

- 餐牌選擇、湯底、加配料、走蛋減價及自訂限定餐點。
- 免費項目及指定項目照原價。
- 可選「$78 麵唔參與分攤」，以整碗調整後價錢為準。
- 小食按指定人數平均分，輸入相同名字會按人合計。
- 每位餐點、應付總額及分攤百分比。
- 以仙計算，採用最大餘數分配尾數，確保應收總數等於實付。

## 本機使用

喺 repository 目錄執行：

```sh
python3 -m http.server 8765 --directory dist
```

瀏覽 http://localhost:8765 。亦可以直接用瀏覽器開啟 `dist/index.html`。

輸入餐點，指定照原價項目，再填寫張單實付總額。剩餘金額會按其他項目原價比例分攤。百分比表示分攤池內嘅比重，唔係佔整張單嘅百分比。

## 測試

需要 Node.js，毋須額外套件：

```sh
node tests/calculator.cjs
```

涵蓋餐牌價錢、免費項目、照原價、$78 規則、多人小食、輸入驗證、百分比及 1,000 組金額合計測試。

## 限制

- 清單只存在目前頁面，重新整理會清空。
- 午市優惠資格由使用者按餐廳實際規則確認。
- 小食先平均分至仙，再加入各人分攤權重；尾數可能令百分比有輕微差異。
- 餐牌相來自使用者提供嘅照片，紅筆標記經 AI 清理；餐牌內容及商標屬相關權利人。
